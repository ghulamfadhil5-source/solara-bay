Solara Bay is a 3D open-world crime game set in an original sun-soaked coastal city: drive through the streets, steal cars, outrun the Bay PD, take on 4 story missions, and track it all on a HUD with a live minimap.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
